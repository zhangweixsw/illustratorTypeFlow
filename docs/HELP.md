# Illustrator 智能输入法使用帮助

版本：v1.0.0  
发布：mootop.top  
价格：免费

## 这是什么

Illustrator 智能输入法是一个 Windows 托盘小工具。它盯着 Illustrator 当前正在操作的位置：需要输入中文时打开中文输入状态，回到画布快捷键、尺寸、坐标、字号这类参数框时切回英文。

它不替你敲键盘，也不会改 Illustrator 文件。程序只调整当前输入法的中英文状态。

## 系统要求

- Windows 10 或 Windows 11，64 位
- Adobe Illustrator 2026
- 已安装一个中文输入法，例如微软拼音或微信输入法
- 主程序无需另外安装 .NET

## 安装

1. 下载并解压 `IllustratorTypeFlow-v1.0.0-Windows-x64.zip`。
2. 右键 `安装.ps1`，选择“使用 PowerShell 运行”。
3. 如果系统弹出脚本执行提示，确认脚本来自 mootop.top 后继续。
4. 安装完成后，任务栏右下角会出现程序图标。

默认安装位置是：

```text
%LOCALAPPDATA%\IllustratorTypeFlow
```

安装脚本会为当前 Windows 用户设置开机启动，不需要管理员权限。

如果双击脚本没有反应，也可以在解压目录打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\安装.ps1
```

## 日常使用

正常情况下，安装完就不用管了。程序会按下面的规则切换：

| 当前操作 | 输入状态 |
| --- | --- |
| 画布文字编辑、图层或画板重命名 | 中文 |
| 普通文字输入框 | 中文 |
| 宽高、坐标、字号、角度、透明度等参数框 | 英文 |
| 画布上使用 V、A、P、T 等单键快捷键 | 英文 |
| 切到其他软件 | 恢复进入 Illustrator 之前的状态 |

程序沿用你当前选中的中文输入法，不会擅自把微软拼音换成别的输入法。

## 托盘菜单

- `启用智能切换`：临时暂停或恢复。
- `开机启动`：控制是否随 Windows 登录启动。
- `将当前输入框设为文字框`：某个第三方插件输入框识别错了，可以手动告诉程序“这里要中文”。
- `将当前输入框设为参数框`：把误判为文字框的数字输入位置改回英文。
- `清除当前输入框规则`：删除上面保存的手动规则。
- `无插件校正：正在编辑画布文字`：少数画布文字场景没有自动识别时，手动校正当前状态。
- `复制当前诊断信息`：出现误判时复制现场信息，方便排查。
- `打开日志目录`：查看设置和日志。
- `使用帮助`：打开 mootop.top 在线帮助。

## 常见问题

### 装好后没有看到窗口

这是托盘程序，不会一直占一个窗口。请点任务栏右下角的“显示隐藏的图标”，找到 Illustrator 智能输入法图标。

### 快捷键还是被中文输入法吃掉

先确认托盘菜单里的“启用智能切换”已经勾选。然后在画布空白处点一下，再试 `V`、`A`、`P`。如果仍然不对，用“复制当前诊断信息”把结果保存下来。

### 某个插件输入框切换错了

把光标放进那个输入框，在托盘菜单选择“设为文字框”或“设为参数框”。这个规则会保存在本机，下次仍然有效。

### 程序会上传设计稿吗

不会。状态判断、设置和日志都在本机完成。程序不读取或上传 Illustrator 文档内容。

### 安全软件拦截怎么办

这个版本是体积较大的自包含单文件程序，首次启动时个别安全软件可能会多检查一会儿。请只从 mootop.top 商品页或 GitHub Release 下载，并核对页面公布的 SHA-256。

## 卸载

关闭 Illustrator 后，在解压目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\卸载.ps1
```

如果想保留设置和日志：

```powershell
powershell -ExecutionPolicy Bypass -File .\卸载.ps1 -KeepSettings
```
